# 🛍️ تطبيق إدارة المنتجات - Flask

تطبيق ويب بسيط وسهل الاستخدام لإدارة المنتجات باستخدام Flask و Jinja2 و HTML/CSS.

## ✨ المميزات

- **عرض المنتجات**: عرض جميع المنتجات في شبكة جميلة وسهلة الاستخدام
- **إضافة منتج**: إضافة منتجات جديدة مع اسم وسعر وتفاصيل وصورة
- **عرض التفاصيل**: عرض معلومات كاملة عن كل منتج
- **تعديل المنتج**: تحديث معلومات المنتج
- **حذف المنتج**: إزالة المنتجات غير المرغوبة
- **واجهة جميلة**: تصميم حديث وسريع الاستجابة
- **دعم اللغة العربية**: واجهة كاملة باللغة العربية

## 📋 المتطلبات

- Python 3.7 أو أحدث
- pip (مدير الحزم)

## 🚀 التثبيت والتشغيل

### 1. استنساخ أو تحميل المشروع

```bash
cd /home/ubuntu/products_app
```

### 2. تثبيت المتطلبات

```bash
pip install -r requirements.txt
```

### 3. تشغيل التطبيق

```bash
python app.py
```

التطبيق سيعمل على العنوان: `http://localhost:5000`

## 🎯 الاستخدام

### الصفحة الرئيسية
- عرض جميع المنتجات المتاحة
- كل منتج يعرض الاسم والسعر والوصف المختصر
- أزرار للعرض والتعديل والحذف

### إضافة منتج جديد
1. انقر على زر "إضافة منتج" في الشريط العلوي
2. ملء النموذج بمعلومات المنتج:
   - اسم المنتج (مطلوب)
   - السعر بالريال (مطلوب)
   - تفاصيل المنتج (مطلوب)
   - رابط الصورة (اختياري)
3. انقر على "إضافة المنتج"

### عرض تفاصيل المنتج
1. انقر على زر "عرض التفاصيل" على أي منتج
2. ستظهر جميع معلومات المنتج بشكل مفصل

### تعديل منتج
1. من الصفحة الرئيسية أو صفحة التفاصيل، انقر على "تعديل"
2. عدّل المعلومات المطلوبة
3. انقر على "حفظ التغييرات"

### حذف منتج
1. انقر على زر "حذف" على أي منتج
2. أكد عملية الحذف في النافذة المنبثقة

## 🛠️ التقنيات المستخدمة

- **Flask**: إطار عمل Python للويب
- **Jinja2**: محرك قوالب لإنشاء صفحات ديناميكية
- **HTML5**: لبناء هيكل الصفحات
- **CSS3**: لتصميم وتنسيق الواجهات
- **Python**: لغة البرمجة الأساسية

## 📝 ملاحظات مهمة

- البيانات تُخزن في الذاكرة فقط (لا توجد قاعدة بيانات دائمة)
- عند إعادة تشغيل التطبيق، ستُفقد جميع البيانات المضافة
- لحفظ البيانات بشكل دائم، يمكن إضافة قاعدة بيانات مثل SQLite أو MySQL
